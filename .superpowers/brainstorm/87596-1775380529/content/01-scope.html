How should Chalk handle mobile/tablet navigation?

The sidebar (groups list) is hidden below 1024px with no alternative. What scope makes sense?

A

Minimal fix — just unblock navigation

Add a hamburger/drawer toggle so users can access the groups sidebar on small screens. Keep the existing layout, just make it accessible. Smallest scope, least disruption.

B

Mobile-adapted — rethink the layout for small screens

Replace the sidebar with a mobile-native pattern: bottom tab bar, top dropdown, or a groups list as the default mobile "home" view. More polished feel, more work.

C

Full responsive redesign — desktop + mobile optimized

Redesign layout for all breakpoints: desktop stays as-is, tablet gets a collapsible sidebar, mobile gets a completely different navigation pattern (bottom tabs, swipe gestures, etc).
